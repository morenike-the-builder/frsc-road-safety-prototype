# FRSC Mobility Course - Quick Start Guide

## 🚀 Getting Started in 30 Seconds

### 1. Open the App
Simply open `index.html` in your web browser:
- **Double-click** `index.html` in Finder
- **Or** right-click → "Open With" → your preferred browser
- **Or** drag the file into your browser window

### 2. Explore the Platform
You'll see a mobile app interface with:
- **Home** - Overview of your learning progress
- **Learn** - Browse all 15 FRSC road safety modules
- **Bookings** - Schedule simulator and driving school sessions
- **Tracker** - View your 4-phase licensing pathway

### 3. Try a Module
1. Tap the **Learn** button in bottom navigation
2. Click on any module (try **Module 1: Introduction to Road Safety**)
3. You'll see:
   - **Video Lesson** tab with embedded YouTube video
   - **Reading Material** tab with detailed curriculum text
   - Interactive quiz question
   - AI Assistant ("Ask Cubbes") for clarifications

### 4. Interact with Features

#### Watch a Video Lesson
- Click the video to play
- Use YouTube player controls (play, pause, fullscreen, etc.)
- Each video is 5-12 minutes long

#### Switch to Text Learning
- Click the **Reading Material** tab
- Read the curriculum content at your own pace
- Switch back to video anytime

#### Take the Quiz
- After learning, scroll down to "Interactive Check"
- Select your answer
- Get instant feedback
- Earn 20 XP for correct answers

#### Ask the AI
- Scroll to "Ask Cubbes AI Assistant"
- Type your question about the module
- Get context-aware responses based on FRSC guidelines

#### Track Your Progress
- Home screen shows your completion % (13% initially)
- Each completed module unlocks the next
- Your XP points increase with each correct answer

## 📱 Mobile-First Design

The app is optimized for **480px width** (iPhone SE / standard mobile size) but works on:
- ✅ Tablets (iPad, Android tablets)
- ✅ Desktops (Firefox, Chrome, Safari, Edge)
- ✅ Any modern browser with JavaScript enabled

For mobile testing: Open DevTools (F12) and toggle **Device Toolbar** to see mobile view.

## 🎯 Key Features Explained

### Module Structure
Each of the 15 modules includes:
- **Learning Outcomes** - What you'll understand after completion
- **Topics** - Key concepts covered
- **Video Lesson** - 📺 Watch the instructor (NEW!)
- **Reading Material** - 📖 Read detailed content
- **Interactive Quiz** - ❓ Test your knowledge
- **AI Assistant** - 🤖 Get help with questions

### Progress System
- ⭐ **Completed** - You passed the quiz
- 🔄 **In Progress** - Currently working on it
- 🔓 **Unlocked** - Ready to start
- 🔒 **Locked** - Complete previous phases first

### 4-Phase Learning Path
1. **Phase 1** - Digital Road Safety Education (15 modules) ← You are here
2. **Phase 2** - Simulation & Driving Readiness (simulator booking)
3. **Phase 3** - Accredited Driving School (on-road lessons)
4. **Phase 4** - Official FRSC Driver's License (certification)

## 🐛 Troubleshooting

### Videos Don't Load
- ✓ Check your internet connection
- ✓ YouTube videos require internet (no offline mode yet)
- ✓ Try refreshing the page
- ✓ Try a different browser

### Quiz Not Working
- ✓ Make sure JavaScript is enabled
- ✓ Try clearing browser cache (Ctrl+Shift+Delete)
- ✓ Try a different browser

### App Looks Weird
- ✓ Your browser window is too small → resize
- ✓ Try refreshing (Ctrl+R or Cmd+R)
- ✓ Clear cookies/cache and reload

### Data Not Saving
- ✓ Data is stored **in browser memory only** (not saved to server yet)
- ✓ Refreshing the page resets your progress
- ✓ Backend persistence coming in Phase 2

## ❓ Frequently Asked Questions

**Q: Can I use this on my phone?**

**Q: Is my data stored somewhere?**  
A: Currently in-browser only. Full user accounts coming with backend.
