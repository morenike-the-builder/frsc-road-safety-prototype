# FRSC Road Safety & Responsible Mobility Prototype

Interactive student learning experience for the Federal Road Safety Commission (FRSC) in Nigeria.

## Overview

This prototype demonstrates the Cubbes-powered digital road safety programme designed for Nigerian university students. It showcases:

- **Returning User Experience** - 40% progress, session resumption, gamification stats
- **Interactive Learning** - Hazard perception, sequence ordering, decision-based scenarios
- **Smart Progress Tracking** - Module completion, XP earned, day streaks
- **Driving School Marketplace** - FRSC-accredited schools, ratings, booking
- **Professional Certification** - Digital certificates subject to FRSC approval

## Features

✅ Home screen with weekly stats (XP, modules, streaks, progress)  
✅ Course overview showing 3 completed + current module  
✅ Session resume with progress bar  
✅ Multiple question types: hazard perception, sequencing, scenarios  
✅ Assessment results with knowledge area breakdown  
✅ Driving school marketplace with 3 options  
✅ Digital certificate with FRSC/Cubbes co-branding  
✅ What's Next progression guide  

## Design

Built with the **Cubbes Scholar Skills design system**:
- Font: Inter
- Brand Color: #2f4bff (Cubbes Blue)
- Responsive mobile-first (430px width)
- Smooth animations and interactions
- Cubes color palette: blue, green, yellow, red

## How to Use

1. Open `index.html` in a browser
2. Click through the student journey:
   - Home → Course Overview
   - Resume Module 4 or Start Module 5
   - Complete learning screens
   - View assessment results
   - Select driving school
   - Get certificate
   - See What's Next

## Context

This prototype was created for presentation to FRSC leadership in Abuja, demonstrating:
- How students experience the digital road safety curriculum
- Progress tracking and engagement mechanisms
- Integration with FRSC-accredited driving schools
- Professional certification pathway

The demo emphasizes that Cubbes is the **implementation partner**, not the center—FRSC remains the authority on curriculum, standards, and certification.
